# Как собирается страница комплекта

`package/index.html` — **собранный файл**, его не редактируют руками.
Он склеивается скриптом из трёх источников:

| Источник | Куда попадает |
|---|---|
| содержимое раздела «Комплект» | вкладка «Комплект» |
| `package/voronka-praktikum.html` | вкладка «Воронка на практикум» |
| `package/tehkontrakt.html` | вкладка «Техконтракт» |

Правки вносятся в `voronka-praktikum.html` и `tehkontrakt.html`,
после чего страница пересобирается и публикуется заново.

Квиз и прототип воронки живут отдельными артефактами, потому что просмотрщик
артефактов блокирует переходы между файлами внутри одной публикации:

- квиз — собирается из корневого `index.html` в `artifacts/kviz.html`;
- прототип — из `voronka.html` в `artifacts/voronka-prototip.html`.

Сборка снимает внешнюю оболочку документа (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`),
потому что публикация добавляет её сама.
